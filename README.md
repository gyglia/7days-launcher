# 7 Days Launcher

Лаунчер для клиентской сборки Sever2026 в 7 Days to Die 3.4 (Windows / Steam).

![Лаунчер](docs/launcher.png)

## Скачать и запустить

Скачайте **JAGO-Launcher.exe** в [последнем релизе](https://github.com/gyglia/7days-launcher/releases/latest) и запустите его. Техническое имя файла сохранено для совместимости с установленными копиями и ярлыками.

Лаунчер находит игру в Steam. Если папка не найдена, выберите её через шестерёнку. Доступное обновление сборки устанавливается автоматически; прогресс отображается кровавой полосой. Кнопка **7 Days** запускает игру без EAC и подключает к серверу `185.189.255.19:27100`.

Если Steam закрыт или вход не выполнен, лаунчер открывает Steam и ждёт авторизации до пяти минут. Пароль и Steam Guard вводятся в Steam. После запуска игры лаунчер ждёт её авторизации в Steam, передаёт подключение и закрывается при подтверждении начала соединения. При ошибке остаётся открытым с сообщением.

Окно перетаскивается за арт. Настройки, сворачивание и выход доступны через шестерёнку. В оформлении используются прозрачный контур сцены, анимированный зомби, частицы, мерцающая лампа и плавный переход к красной луне при запуске.

## Данные и обновления

### Обновление модов из файла

Начиная с `1.2.0`: откройте настройки → **Выбрать архив** → укажите скачанный полный ZIP сборки → **Готово**. Доступ к GitHub при установке из файла не требуется. Игра должна быть закрыта. Пока архив не выбран, «Готово» неактивно. Прогресс отображается той же полосой, что и автоматическое обновление.

Полный архив `Sever2026-offline.zip` приложен к релизу `v1.2.0`. Он содержит `manifest.json` и ZIP каждого пакета в корне. Проверяются состав, версия игры, размеры и SHA-256 всех пакетов до изменения модов. Неполный архив или ZIP отдельного мода не подходят. Используется обычная установка с резервной копией и откатом при ошибке. Новые полные архивы сборки должны содержать актуальный манифест и все указанные в нём пакеты.

Скрипт сборки также создаёт `dist/Sever2026-offline.zip` для встроенной базовой сборки.

- Файлы лаунчера: `%LOCALAPPDATA%\JAGO`.
- Моды и резервная копия заменяемых файлов: `%APPDATA%\7DaysToDie`.
- Журналы подключения: `%LOCALAPPDATA%\JAGO\logs\join-*.log`.
- Обновления модов: [gyglia/jago-releases](https://github.com/gyglia/jago-releases). Версия приложения и версия комплекта модов `sever2026.1` независимы. Обновление лаунчера скачивает только EXE; обновление сборки — только изменившиеся пакеты по SHA-256. При первой установке скачиваются все нужные пакеты.
- Начиная с `1.1.0`, лаунчер автоматически проверяет стабильный последний релиз этого репозитория при открытии и через кнопку «Проверить». Новая версия скачивается с прогрессом, проверяется по SHA-256 из GitHub API и версии внутри EXE, затем устанавливается с перезапуском. Обновляются запущенная и установленная копии. При ошибке замены выполняется откат. Недоступность GitHub не мешает обычному запуску. Ошибки проверки записываются в `%LOCALAPPDATA%\JAGO\self-update-error.txt`, ошибки замены — в `%LOCALAPPDATA%\JAGO\updates\<идентификатор>\error.txt`.
- Пользователям `1.0.0` нужно один раз скачать `1.1.0` вручную: в первом релизе механизма самообновления ещё нет.

## Сборка

Нужны Windows, Windows PowerShell 5.1 или PowerShell 7 и .NET Framework 4.x с WPF и компилятором `csc.exe`.

1. Склонируйте репозиторий.
2. Из релиза `v1.0.0` скачайте `launcher-build-inputs.zip` и распакуйте в корень репозитория. Получится каталог `installer/payload` с семью исходными ZIP модов. Они хранятся отдельно от истории Git.
3. Выполните из корня:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File installer/build-launcher.ps1
```

Результат: `dist/JAGO-Launcher.exe` и `dist/manifest.json`. Начиная с 1.3.0, EXE содержит только приложение и арт (около 15 МБ). Моды в него не встроены. Отдельные пакеты появляются в dist/packages, полный архив — в dist/Sever2026-offline.zip. SHA256SUMS.txt в релизе содержит контрольные суммы опубликованных файлов.

## Проверки

```powershell
Start-Process .\dist\JAGO-Launcher.exe -ArgumentList '--ui-test dist\ui-test.txt' -Wait
Start-Process .\dist\JAGO-Launcher.exe -ArgumentList '--launcher-test dist\launcher-test.txt' -Wait
Start-Process .\dist\JAGO-Launcher.exe -ArgumentList '--self-update-test dist\self-update-test.txt' -Wait
Get-Content .\dist\ui-test.txt, .\dist\launcher-test.txt, .\dist\self-update-test.txt
```

Проверки интерфейса не запускают игру. Проверка установки работает в отдельной временной папке. `--demo` открывает безопасную демонстрацию интерфейса. Реальное соединение с сервером требует установленной игры, авторизации Steam и доступного сервера.

Исходники интерфейса: `installer/LauncherDesign.cs`; запуск и состояния: `installer/LauncherWindow.cs`; обновления: `installer/LauncherRelease.cs`. Сторонние моды принадлежат их авторам; этот репозиторий не меняет условия их использования.

## Выпуск версии лаунчера

Обновите обе версии в `installer/AssemblyInfo.cs`, соберите и проверьте EXE. Создайте стабильный GitHub Release с тегом `vX.Y.Z`, совпадающим с версией EXE `X.Y.Z.0`, и приложите `JAGO-Launcher.exe`. GitHub должен вернуть `digest` формата `sha256:…` для этого файла. Сначала загрузите файл в черновик, проверьте digest и только затем публикуйте релиз как Latest. Предварительные версии и понижение версии не устанавливаются. Архив исходных модов остаётся доступным в `v1.0.0`.
