# 7 Days Launcher

Лаунчер для клиентской сборки Sever2026 в 7 Days to Die 3.4 (Windows / Steam).

![Лаунчер](docs/launcher.png)

## Скачать и запустить

Скачайте **JAGO-Launcher.exe** в [последнем релизе](https://github.com/gyglia/7days-launcher/releases/latest) и запустите его. Техническое имя файла сохранено для совместимости с установленными копиями и ярлыками.

Лаунчер находит игру в Steam. Если папка не найдена, выберите её через шестерёнку. Доступное обновление сборки устанавливается автоматически; прогресс отображается кровавой полосой. Кнопка **7 Days** запускает игру без EAC и подключает к серверу `185.189.255.19:27100`.

Если Steam закрыт или вход не выполнен, лаунчер открывает Steam и ждёт авторизации до пяти минут. Пароль и Steam Guard вводятся в Steam. После запуска игры лаунчер ждёт её авторизации в Steam, передаёт подключение и закрывается при подтверждении начала соединения. При ошибке остаётся открытым с сообщением.

Окно перетаскивается за арт. Настройки, сворачивание и выход доступны через шестерёнку. В оформлении используются прозрачный контур сцены, анимированный зомби, частицы, мерцающая лампа и плавный переход к красной луне при запуске.

## Данные и обновления

- Файлы лаунчера: `%LOCALAPPDATA%\JAGO`.
- Моды и резервная копия заменяемых файлов: `%APPDATA%\7DaysToDie`.
- Журналы подключения: `%LOCALAPPDATA%\JAGO\logs\join-*.log`.
- Обновления модов: [gyglia/jago-releases](https://github.com/gyglia/jago-releases). Версия приложения `1.0.0` и версия комплекта модов `sever2026.1` независимы.
- Новые версии самого лаунчера скачиваются из Releases вручную.

## Сборка

Нужны Windows, Windows PowerShell 5.1 или PowerShell 7 и .NET Framework 4.x с WPF и компилятором `csc.exe`.

1. Склонируйте репозиторий.
2. Из релиза `v1.0.0` скачайте `launcher-build-inputs.zip` и распакуйте в корень репозитория. Получится каталог `installer/payload` с семью исходными ZIP модов. Они хранятся отдельно от истории Git.
3. Выполните из корня:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File installer/build-launcher.ps1
```

Результат: `dist/JAGO-Launcher.exe` и `dist/manifest.json`. EXE содержит базовый комплект из 34 модов. SHA256SUMS.txt в релизе содержит контрольные суммы опубликованных файлов.

## Проверки

```powershell
Start-Process .\dist\JAGO-Launcher.exe -ArgumentList '--ui-test dist\ui-test.txt' -Wait
Start-Process .\dist\JAGO-Launcher.exe -ArgumentList '--launcher-test dist\launcher-test.txt' -Wait
Get-Content .\dist\ui-test.txt, .\dist\launcher-test.txt
```

Проверки интерфейса не запускают игру. Проверка установки работает в отдельной временной папке. `--demo` открывает безопасную демонстрацию интерфейса. Реальное соединение с сервером требует установленной игры, авторизации Steam и доступного сервера.

Исходники интерфейса: `installer/LauncherDesign.cs`; запуск и состояния: `installer/LauncherWindow.cs`; обновления: `installer/LauncherRelease.cs`. Сторонние моды принадлежат их авторам; этот репозиторий не меняет условия их использования.
